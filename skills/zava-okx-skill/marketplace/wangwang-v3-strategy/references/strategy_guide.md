# 汪汪汪·V3策略原理详解

## 设计哲学

**少交易，抓趋势，保本第一。**

核心假设：市场80%时间是震荡，趋势只在20%时间出现。策略目标是在趋势来临时重仓持有，在震荡时轻仓或空仓。

## 入场系统

### 第一层：趋势确认（权重70%）

**EMA双线交叉**
- 快线(20周期)上穿慢线(55周期) → 多头信号
- 快线下穿慢线 → 空头信号
- EMA距离越大，信号越强

**Supertrend方向**
- 价格在HL2+2.5×ATR上方 → 上升趋势
- 价格在HL2-2.5×ATR下方 → 下降趋势
- Supertrend方向改变时，信号强化或反转

**Directional Movement（DI）**
- +DI > -DI → 多头动能
- -DI > +DI → 空头动能
- DI差值越大，方向越明确

### 第二层：ADX过滤（趋势强度）

| ADX值 | 市场状态 | 策略行为 |
|-------|---------|---------|
| >40 | 强趋势 | 全额信号，积极入场 |
| 25~40 | 有趋势 | 正常信号 |
| <25 | 震荡 | 信号削弱70%，减少假信号 |
| <15 | 无趋势 | 基本不开仓 |

**为什么ADX<25时要削弱而不是完全不开仓？**
- ADX是滞后指标，有时趋势已经启动但ADX还未突破25
- 保留30%信号，可以抓住趋势的早期阶段

### 第三层：动量确认（权重20%）

**RSI（14周期）**
- RSI > 50 → 多头动能
- RSI < 50 → 空头动能
- RSI > 70 / < 30 → 超买超卖，信号放大

**MACD Histogram**
- Histogram > 0 → 多头势能
- Histogram < 0 → 空头势能
- Histogram扩大 → 动能增强

### 综合信号

```
composite = 0.7×趋势信号 + 0.2×动量信号 + 0.1×波动率信号

|composite| > 0.28 → 入场
|composite| < 0.24 → 出场观望
```

## 止损系统

### 固定止损
```
止损距离 = 2.5 × ATR
止损价格 = 入场价 ± 止损距离
```

### 移动止损（Trail Stop）
- 当浮盈达到 **5.5%** 时激活
- 止损线 = 最高/最低价 - 2.0×ATR
- 只移动不退后，保护已有利润

### 止盈
```
止盈距离 = 止损距离 × 4.0
盈亏比 = 4:1
```

理论上：1次盈利可覆盖4次止损。

## 滚仓复利系统

### 触发条件
- 浮盈达到 **10%** 时触发
- 最多滚仓 **3次**

### 操作逻辑
1. 计算当前未实现盈亏
2. 取 **50%** 浮盈作为新仓保证金
3. 新仓独立设置止损止盈
4. 原仓位止损自动移到**成本价**（零风险敞口）

### 滚仓收益示例
```
初始仓: 1 BTC @ $70,000，止损$68,000（风险$2,000）
滚仓1: +$1,000浮盈 → 加0.5 BTC @ $71,000
滚仓2: +$2,000浮盈 → 再加0.5 BTC @ $72,000
滚仓3: +$3,000浮盈 → 再加0.5 BTC @ $73,000
最终:   2.5 BTC，成本均价 $71,200
```

滚仓使同样的趋势赚取更多利润，但也会放大亏损风险。

## 仓位管理

### 仓位计算
```
单笔保证金 = 账户权益 × 8%
最大仓位 = 账户权益 × 18%
杠杆 = 15x（最高18x）
```

### 多空双向
- `long_bias = 0.5` → 完全对称，多空机会均等
- `long_bias = 1.0` → 只做多
- `long_bias = 0.0` → 只做空

## 回测局限性

1. **不考虑滑点**：实际成交价可能比回测差0.05%~0.2%
2. **不考虑手续费**：高杠杆交易手续费影响显著
3. **资金费率**：永续合约的资金费率未计入
4. **流动性**：极端行情下强平价附近可能无法成交
5. **数据源**：Binance 15m数据可能存在交易所差异

**建议**：回测夏普比 > 0.4、最大回撤 < 35%、零爆仓 的策略才考虑实盘。
